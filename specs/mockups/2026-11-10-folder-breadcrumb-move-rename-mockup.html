Folder breadcrumb: move and rename

A menu on the right of the folder breadcrumb bar offers Rename folder, Move folder and Move into your library for the folder you are in. Tiles and sidebar items have no actions in this version; open the folder to rename or move it.

Placement. The menu sits on the right of the existing ControlBar, after the breadcrumbs. The back arrow stays on the left.
Scope. Actions apply to the folder shown in the bar (the last crumb). Tiles and sidebar items have no menu in this version.
Library roots. The menu is hidden on an external library or user library root, because moving it would be a library-level change.
Read-only. Items stay visible but disabled, with a reason. The server repeats the check at action time.
Import into library. The menu item opens a confirmation (stage 5) before anything moves. It lists every file under the folder with its path relative to the folder and the name the storage template gives it in your user library; a name taken by an earlier file in the same batch gets the +N suffix. Confirming starts the same background job as a move (stages 7 to 9). The external move picker (stage 4) still lists external libraries only.
States. Read-only destination: the picker shows the reason and Move here is disabled (stage 6). In progress: a progress panel, not a notification, so it stays out of the drawer (stage 7). Succeeded: a toast that dismisses itself (stage 8). Failed: a toast that stays until dismissed, plus one drawer entry (stage 9).
Top bar. Shown in every stage. The bell opens the notification drawer. It shows an unread dot only while a notification is unread, which is the failed move (stage 9, drawer open).
