Placement. The pencil sits on the filename row, next to the existing location button. The date row already has an owner-only pencil for the same kind of edit.
Why not the overflow menu. The filename is already in the info panel, and the viewer's overflow menu already holds many actions. Two entry points for one value would drift apart, so the mockup uses one.
Who can rename. Owners only, gated like the date pencil. A space viewer sees the filename and location button with no pencil (stage 4).
Dialog. The name field is the filename without its extension. The extension is shown after the field and cannot be changed here.
Open. The mockup does not decide whether the file on disk is renamed or only the name Gallery shows. That needs a decision before the rename spec.
